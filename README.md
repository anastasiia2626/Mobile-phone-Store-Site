# Mobile-phone-Store-Site
Сайт інтернет-магазину мобільних телефонів  для людей, які шукають смартфон собі чи на подарунок, який дозволяє обрати та оформити замовлення із самовивозом або доставкою за 5 секунд за допомогою купівлі в один клік із прив'язаним профілем - на відміну від традиційних онлайн-магазинів із багатокроковими формами оформлення.
Аналоги: comfy.ua, foxtrot.com.ua, citrus.ua.
